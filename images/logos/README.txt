RECOMMENDED SIZE / FORMAT
-------------------------
- Format:   Transparent-background PNG (preferred) or SVG.
- Height:   ~100 px tall  (displayed at ~46 px; 100 px keeps it crisp on
            high-resolution/retina screens).
- Width:    Automatic / proportional — DO NOT stretch. Keep each logo's
            natural aspect ratio. Aim for a max width of ~380 px so very
            wide logos don't dominate the row.
- Think of it as: fit each logo inside a 380 x 100 px transparent box,
            centered, with a little padding.
- File size: keep each under ~50 KB.

NOTE ON COLOUR
--------------
The site is monochrome, so the carousel displays all logos in greyscale
by default and reveals full colour on hover. You can supply the normal
full-colour logos — the styling handles the greyscale look automatically.
