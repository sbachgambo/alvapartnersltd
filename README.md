# Alva Partners — Website

Static marketing website for **Alva Partners Limited** (Gwarinpa, Abuja, Nigeria) — business
solutions & consulting, and renewable-energy products as an official NASENI Devfrontier partner.

## Pages
| File | Page |
|------|------|
| `index.html` | Home |
| `about.html` | About |
| `services.html` | Services |
| `solar.html` | Renewable Energy — solar product catalogue + "Request a Quote" form |
| `portfolio.html` | Projects |
| `news.html` | News & Insights |
| `contact-us.html` | Contact |

## Shared assets
- `styles.css` — shared design system (brand palette, typography, header/nav, footer, buttons)
- `main.js` — mobile navigation toggle
- `images/` — photography and image assets

## Brand
- Graphite `#232323` (primary) + Solar Amber `#E0892B` (accent), derived from the ALVA logo
- Fonts: Cinzel (logo), Playfair Display (headings), Inter (body)

## Setup notes
- The **contact** and **quote** forms use [Web3Forms](https://web3forms.com) (no backend needed).
  Replace `YOUR_WEB3FORMS_ACCESS_KEY` in `contact-us.html` and `solar.html` with a free access key.

Built with plain HTML, CSS, and JavaScript — no build step required.
